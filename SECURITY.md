# Security

The frontend is public code and cannot keep secrets. Provider keys, OAuth client secrets, workspace authorization and privileged operations belong on the server. Do not submit real credentials, customer content, private logs or exploitable production details in a public issue.

For a sensitive report, request a confidential reporting channel from the maintainer without posting the sensitive details. Use synthetic reproductions when discussing a browser or contract defect publicly. No deployed application or verified production security posture is claimed by this repository setup.
